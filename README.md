# 🚀 H17-TeamBF-IPO-Web-Application

A comprehensive, full-stack platform for IPO discovery, tracking, and analytics. Seamlessly manage, analyze, and explore IPO opportunities with a modern, intuitive interface.

---

## ✨ Features

- **IPO Listings:** Browse all current, upcoming, and past IPOs with detailed information.
- **Company Profiles:** Access background info and financials for companies launching IPOs.
- **Application Tracker:** Track your IPO applications and view allotment status in real time.
- **Performance Analytics:** Visualize post-listing performance with interactive charts and analytics.
- **Personal Watchlist:** Add IPOs to your watchlist to follow their updates and outcomes.
- **User Authentication & Security:** Sign up and log in securely, protected by Google reCAPTCHA.
- **Responsive Design:** Fully optimized for mobiles, tablets, and desktops.
- **Admin Panel:** (If present) Easily add or update IPO information and manage users.
- **Notifications:** Stay up-to-date with the latest IPO news and important alerts.
- **Modern UX:** Fast navigation and smooth user experience powered by React.

---

## 🛠️ Tech Stack

**Frontend:**
- React 19
- React Router DOM
- Google reCAPTCHA
- Testing Library (Jest, React Testing Library)
- Modern CSS

**Backend:**
- Node.js, Express
- CORS
- Path

## 📦 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yvishwas40/H17-TeamBF-IPO-Web-Application.git
cd H17-TeamBF-IPO-Web-Application
```

### 2. Install Dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd ../backend
npm install
```

### 3. Run the Application

#### Start Backend

```bash
cd backend
node index.js
```

#### Start Frontend

```bash
cd ../frontend
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
